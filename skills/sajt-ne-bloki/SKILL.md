# Сайт, а не лендинг из блоков

Проблема: лендинги выходят «из блоков» (первый экран → преимущества → карточки → отзывы → FAQ, меняются только картинки). Скил собран по ролику «GPT-6 Astra делает невероятные сайты без нейрослопа» + собственные правила.

**Главная мысль:** проектируем не набор секций, а то, что посетитель ПЕРЕЖИВАЕТ, пока листает. Секции — следствие сценария, а не стартовая точка.

## До начала (обязательно прочитать)
- чек-лист «Музей AI-слопа» (40 клише, https://ai-slop.matvei-vibecoder.com).
- Свой чек-лист замечаний заказчика, вести и пополнять (ползунки, 2560 px, кадр за секунду, полные фразы, scrollWidth на телефоне…).
- Образец заказчика даёт ФУНКЦИИ; вид — свой, если он не сказал «как тут по виду». Сомневаешься — спроси одной фразой.

## Шаг 1. Бриф (2–3 фразы) — спросить, чего не хватает
Кто делает, что в этом особенного (факт, а не «качество»), для кого и в какой ситуации человек сюда приходит. Пример формы: «Показываем дачнику в сентябре, у которого теплица после сезона в налёте». Факты — только с этикетки/от заказчика; выдуманных цифр нет.

## Шаг 2. Событие прокрутки — одна фраза
«Пока человек листает, он видит, как ___ превращается в ___». Примеры: грязная теплица становится чистой; почва под землёй «оживает» слой за слоем; рассада на подоконнике вырастает за 10 секунд; меняется температура света — и меняется вся страница. Нет события — нет сайта, дальше не идти.

## Шаг 3. Структура — выбрать ОДНУ из 8 (не «стопка блоков»)
1. **Очерк** — титул без картинок, главы с жёсткими склейками (как журнал).
2. **Путешествие** — одна сцена на несколько экранов, камера движется (scroll-видео/3D).
3. **До/после** — страница сама переходит из состояния А в Б по мере прокрутки.
4. **Разбор** — предмет раскладывается на части/слои (состав, как работает внутри).
5. **Сезонный календарь** — время как ось (месяцы/фазы роста), прокрутка = ход времени.
6. **Витрина-коллекция** — проход латерально (горизонтальный pan) по предметам с одной схемой подписи.
7. **Инструмент** — главный экран сам считает/подбирает (калькулятор, конфигуратор), всё вокруг него.
8. **Досье/доказательства** — факты, замеры, фото с участков как материалы дела.
Записать, почему эта, и чем она НЕ станет стопкой блоков.

## Шаг 4. Кривая с одним пиком
Расписать экраны: тишина → нарастание → **ПИК** → разрядка → действие (купить). Пик один на всю страницу, ему больше всего места по прокрутке, перед ним — пауза (воздух, сплошной текст или пустой экран).

## Шаг 5. Карта анимаций — поимённо и к месту
Словарь: pan (латерально), reveal (проявление), count (счётчик — ТОЛЬКО на настоящих цифрах), tilt (наклон того, что хочется взять в руки), parallax внутри медиа-колонки (текст рядом стоит), scrub (видео/кадры идут за прокруткой), pin (сцена закреплена, меняется внутри), kinetic-типографика, mask/clip-переход, morph цвета/света, spotlight, magnet.
Правила: для каждой — ГДЕ и ЗАЧЕМ; явно записать, что НЕ используем; минимум 4 разных семейства; одно и то же два раза подряд не ставить; без анимации страница читается полностью (prefers-reduced-motion).

## Шаг 6. Свой приём
Придумать ОДИН приём, которого нет в словаре и который живёт только на этом сайте (у почвенного удобрения — кружки-вредители под землёй с линиями; у светильника — свет меняет всю страницу). Это самое важное — записать отдельной строкой.

## Шаг 7. Визуальный жанр — словами фотографа
Назвать жанр и технику съёмки (high-key editorial на циклораме / natural documentary, 35 мм, с рук, никто не смотрит в камеру / макро на земле в контровом свете) + запреты (стоковая улыбка, кремово-латунная палитра, нейро-градиенты). Свои фото/ролики заказчика — в приоритете; генерацию — только по согласию.

## Шаг 8. Кадры героя → видео (если структура 2/3/4)
1. Сначала 2–4 варианта КАДРА (картинки дешёвые) → показать заказчику на макете страницы → он выбирает номер.
2. Видео по выбранному кадру — только после «да» заказчика с ценой (Seedance 2 через Higgsfield MCP или Kie.ai: ~$2 за 10 с 720p, ~$5 1080p). Или его собственный ролик.
3. Проигрывание — scrub от прокрутки, кадры на canvas (Яндекс.Браузер рисует кнопки поверх `<video>`), постер-заглушка, отдельный лёгкий файл для телефона.

## Шаг 9. Сборка
Короткий промт самому себе по шаблону ниже → вёрстка с impeccable (`/impeccable` craft/shape; потом critique/audit/polish). Плавная прокрутка (Lenis), без тяжёлых blur.

```
Собери сайт для <бренд/товар>. <Чем особенный — факт>. Показываем <кому, в какой ситуации>.
Мне важно, чтобы это был дизайнерский сайт, а не лендинг из блоков. Конкретно:
Визуал — <жанр съёмки, техника>. <Запреты по визуалу>.
Форма — <метафора структуры из шага 3>.
Событие прокрутки — <фраза из шага 2>.
Анимации от скролла: <какая — где — зачем>. <Что не надо>. Минимум 4 семейства, подряд одно и то же не ставить.
Один пик — <что>. Ему больше всего места, перед ним тишина.
Свой приём — <из шага 6>. Это самое важное.
Постер, если нет WebGL/анимации; без анимации всё читается. Текст русский, шрифт с кириллицей. У всех предметов одна схема подписи, факты, не выдуманные цифры.
```

## Шаг 10. Проверки перед показом (скриншоты 1440, 2560, телефон 390)
- **Тест подмены:** если заменить картинки на другой товар — страница превратится в чужой сайт без правок? Если да — это снова блоки, вернуться к шагам 2–6.
- **Промежуточные состояния:** скриншоты в середине каждой анимации (на 30/60 % прокрутки сцены), а не только в начале и конце.
- Пик действительно самый длинный и заметный; перед ним есть пауза.
- Телефон: scrollWidth = ширине экрана, видео лёгкое, ничего не прыгает.
- Чек-лист замечаний заказчика; Музей AI-слопа — 40.
В отчёте три строки: «Тест подмены: пройден/что поменял», «Чек-лист замечаний: чисто/исправил №…», «Музей AI-слопа: чисто/нашёл и убрал №…».

## Показ заказчику
Сначала сценарий одной таблицей (экран → что видит → анимация) + кадры героя — ДО полной вёрстки, чтобы правки были дешёвыми. Потом готовая страница скриншотами. Новое замечание, которое может повториться, — сразу в чек-лист замечаний.
