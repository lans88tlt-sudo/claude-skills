# Оформление .xlsx на этой машине (openpyxl + Excel COM)

Правила выстраданы на сравнении тарифов двух служб доставки (05.08.2026). Каждая ловушка ниже
реально стреляла — не считай их теорией.

## Главный закон: НИКОГДА не угадывай высоту строк

openpyxl не умеет измерять текст. Любая формула вида `height = len(text) // 4` даёт обрезанный
текст — проверено, заказчик прислал скриншот с обрезкой. Высоту считает **сам Excel**.

## Обязательный конвейер (4 шага, ни один не пропускать)

```
1. Python/openpyxl  — сгенерировать книгу (высоты обычных строк НЕ задавать вообще)
2. Excel COM        — AutoFit + настройка печати + сохранить  → autofit_and_pdf.ps1
3. Excel COM        — экспорт в PDF                            → там же
4. pymupdf          — отрисовать страницы в PNG и ПОСМОТРЕТЬ ГЛАЗАМИ через Read
```

Шаг 4 не формальность: клиппинг подписи в колонке A на листе расчёта нашёлся только глазами,
все программные проверки его пропустили.

Скрипты лежат рядом с этим файлом: `autofit_and_pdf.ps1`, `render_pdf.py`.

```bash
# шаг 2–3
powershell -File "$HOME\.claude\skills\excel-oformlenie\autofit_and_pdf.ps1" -Path "<xlsx>" -Pdf "<pdf>"
# шаг 4
python "$HOME/.claude/skills/excel-oformlenie/render_pdf.py" "<pdf>" "<папка для png>"
```

`pymupdf` ставится один раз: `pip install pymupdf` (poppler/pdftoppm на этой машине НЕТ,
встроенный рендер PDF в Read не работает).

### ⚠ Excel COM КРАДЁТ ФОКУС — сворачивает игру и полноэкранные приложения
Даже с `$excel.Visible = $false` запуск процесса перехватывает фокус у Windows. Человек за
компьютером играл, и каждый прогон сворачивал ему игру.

Правила:
- **Спроси или предупреди**, прежде чем гонять Excel, если не знаешь, чем человек сейчас занят.
- **Собирай все правки и прогоняй ОДИН раз.** Я сделал пять прогонов подряд там, где хватило бы
  одного, — вот это и раздражало.
- После работы проверяй, что процессов не осталось:
  `Get-Process EXCEL -ErrorAction SilentlyContinue`.

## Ловушки, которые стреляли

### 1. AutoFit НЕ РАБОТАЕТ на объединённых ячейках
Excel их молча игнорирует (а иногда схлопывает в нитку). Все `merge_cells` — баннеры, заголовки
разделов, примечания — требуют высоты, посчитанной вручную. Готовая функция:

```python
def wrapped_height(text, total_width, font_size=11, pad=6):
    """total_width = СУММА ширин всех колонок объединения."""
    if not text:
        return 15
    chars_per_line = max(10, int(total_width * (11.0 / font_size) * 0.97))
    line_h = font_size * 1.32
    lines = sum(max(1, math.ceil(len(p) / chars_per_line)) for p in str(text).split('\n'))
    return math.ceil(lines * line_h + pad)
```

В `autofit_and_pdf.ps1` строки с объединениями определяются заранее и пропускаются — не ломай эту
логику.

### 2. Эмодзи в ячейках подменяются чужими глифами
`💰 🚚 📦 🗺 💵 🔌 ⬛ ✔` в Excel на этой машине рисуются посторонними символами (вместо мешка
с деньгами была птичка). **Не использовать вообще.** Разделы выделять заливкой + жирным.
Безопасны: `– — • ₽ № → ≈ ×`. Знак «−» U+2212 заменять на обычный минус.

### 3. Текст режется соседней ЗАПОЛНЕННОЙ ячейкой
Длинная подпись в A выглядит нормально, пока B пустая. Как только в B появилось значение —
подпись обрезается по границе A, и никакой AutoFit не поможет (перенос-то не включён).
Лечится только шириной колонки. Проверять самые длинные подписи в «шапке слева» вручную:
`max(len(подпись))` против `ws.column_dimensions['A'].width`.

### 4. `.ps1` с кириллицей нужен BOM
PowerShell 5.1 читает файл как ANSI(cp1251) → «Р Р°Р±РѕС‚Р°» и ParserError. Писать только
`encoding='utf-8-sig'`:
```python
io.open('script.ps1', 'w', encoding='utf-8-sig').write(text)
```
(Команды, переданные инлайном в тул PowerShell, кириллицу держат нормально — проблема только у файлов.)

### 5. stdout Python на этой машине = cp1251
`print('₽')` или `print('✔')` роняет скрипт `UnicodeEncodeError`. В начало КАЖДОГО скрипта:
```python
import sys, io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8', errors='replace')
```
Даже с этим русский текст в выводе Bash-тула иногда идёт кракозябрами — на результат не влияет,
но не пугайся и не начинай «чинить» кодировку файла.

### 6. openpyxl не считает формулы
Сразу после генерации `data_only=True` вернёт `None` — кэша значений ещё нет. Значения появляются
только после того, как файл открыл и сохранил Excel (шаг 2 конвейера). Проверять так:
```python
wf = openpyxl.load_workbook(P)                 # формулы
wv = openpyxl.load_workbook(P, data_only=True) # значения, посчитанные Excel
```

### 7. Хардкод номеров строк в формулах разъезжается
При перестройке листа ссылки `B18` уехали на `B13` — таблица считала бы по чужим числам.
Позиции блоков объявлять константами В НАЧАЛЕ и проверять ассертами по ходу:
```python
TAR_START = WARN_ROW + 3
...
assert row == TAR_START, f'раскладка съехала: ожидалось {TAR_START}, получено {row}'
```

### 8. Скрытые листы — это РЕШЕНИЕ ЗАКАЗЧИКА, не сбой. Не раскрывать
Заказчик сам прячет листы, которые ему сейчас не нужны (в сравнении доставок он скрыл
«Расчёт стоимости» и «Вердикт», оставив только «Сравнение»).

Я это принял за сбой: увидел, что в PDF попал один лист вместо трёх, придумал версию про
гонку экземпляров Excel и добавил «страховку», которая принудительно возвращала видимость.
Заказчик сказал «это я их и скрыл» — то есть моя автоматика молча отменяла бы его решение
при каждом прогоне. Пришлось откатывать и возвращать листы в скрытое состояние.

**Правило: состояние листов не менять никогда — ни раскрывать, ни прятать.**
`autofit_and_pdf.ps1` теперь просто пропускает скрытые листы и пишет об этом в лог,
чтобы недостача страниц в PDF не читалась как потеря данных.

Урок шире: расхождение «ожидал 7 страниц, получил 3» — это ещё не баг. Сначала выясни,
не намеренное ли это состояние (спроси заказчика), и только потом чини. Проверить состояние
без запуска Excel:
```python
for ws in wb.worksheets: print(ws.title, ws.sheet_state)
```
Менять `sheet_state` можно через openpyxl — Excel для этого поднимать НЕ надо (см. пункт
про кражу фокуса).

### 9. Двойной BOM ломает .ps1 так же, как его отсутствие
Если записать `utf-8-sig` файл, в котором BOM УЖЕ есть, получится два BOM подряд и
`ParserError: The assignment expression is not valid` на первом же `param()`. Правильно:
```python
s = io.open(p, encoding='utf-8-sig').read()   # снимает существующий BOM
s = s.lstrip('﻿')                        # добивает второй, если он попал в текст
io.open(p, 'w', encoding='utf-8-sig').write(s)
```
Проверка: `open(p,'rb').read(6)` — должно быть ровно одно `\xef\xbb\xbf`.
После КАЖДОЙ правки .ps1 через Edit проверяй BOM заново.

### 10. Заказчик правит СВОЮ копию — искать её ДО начала работы
24.08.2026: я добавил блок в отчёт на Google Диске, а заказчик всё это время правил копию
на рабочем столе — прислал скриншот со словами «где новые данные?». Его версия ушла далеко:
другие числа, удалённые блоки, вставленная картинка, скрытый лист.

**Перед правкой любого отчёта искать более свежие копии:**
```bash
find ~/Desktop ~/Downloads "<облачный диск>" -iname "*имя*.xlsx" -newermt "<дата>"
```
Нашлась вторая копия — правим ТУ, в которой работает заказчик, и говорим ему про расхождение.
Регенерация из скрипта-генератора при этом ЗАПРЕЩЕНА: она сотрёт всё, что он наделал руками.

**01.10.2026, отчёт на рабочем столе — повторилось:** я пересобирал файл генератором уже ПОСЛЕ того, как отдал его заказчику, а он в это время удалил лишние листы и строки и сохранил. Пересбор в 17:17 затёр его правки, копии в автосохранении не нашлось. Правило: **как только файл отдан заказчику — он его. Генератор больше не запускать.** Нужна правка — спросить, закрыт ли файл, и править точечно через COM поверх ЕГО версии. Excel-процесс без заголовка окна может быть и его открытым файлом — не убивать.

### 11. Правка чужого файла — только через Excel COM, не openpyxl
openpyxl при пересохранении **теряет диаграммы** (картинки переживают, графики нет). Если в книге
есть чарты — хоть на скрытом листе — править только COM'ом.
Что стреляло в COM (24.08.2026):
- `$excel.CutCopyMode = 0` и `= $false` роняют скрипт: типизированный enum принимает только
  `xlCopy`/`xlCut`. Строку просто убрать — в невидимом экземпляре она ни на что не влияет.
- **`Range.NumberFormat` не присваивается вообще** — «Нельзя установить свойство NumberFormat
  класса Range». Формат переносить копированием: `$ws.Range("C5:C6").Copy(); $ws.Range("D5:D6").PasteSpecial(-4122)`
  (xlPasteFormats). Целиком ячейку со значением — `PasteSpecial(-4104)` (xlPasteAll).
- Вставленная картинка тянется за шириной колонок. Перед сменой ширин: запомнить `Width`/`Height`,
  выставить `Placement = 3` (xlFreeFloating), после — вернуть размеры.

### 12. Перед перезаписью — бэкап
```bash
mkdir -p "_архив" && cp "файл.xlsx" "_архив/файл (версия ДД.ММ).xlsx"
```

## Настройки по умолчанию

- **Freeze** сразу под шапкой: `ws.freeze_panes = 'A6'`.
- **Легенда цветов** текстом в строке 2 — какой цвет что значит.
- **Жёлтая заливка = «правится руками»**, помечать все входные ячейки.
- **Печать**: альбомная, `FitToPagesWide = 1`, `PrintTitleRows` на строку шапки. Без этого широкая
  таблица уезжает на 13 страниц вместо 7.
- **Лист-презентация должен быть на ОДНОЙ странице**: `autofit_and_pdf.ps1 -FitTall 1` (добавлено
  24.08.2026 на SEO-итогах — лист разваливался на 2 страницы, где на второй оставались три строки).
  Только для коротких итоговых листов; длинную таблицу `-FitTall 1` сожмёт в нечитаемую мелочь.
- Палитра: зелёный `FFC6EFCE` = выигрыш, красный `FFFFC7CE` = проигрыш, жёлтый `FFFFF2CC` = уточнить,
  шапка `FF4472C4` + белый жирный, раздел `FFD9E1F2`, итоговый баннер `FF70AD47` + белый жирный.

## Содержательные правила (не только форматирование)

- Числа, которые заказчик может показать наружу, снабжать **честной оговоркой** прямо в листе:
  на чём построена модель и что её ломает. В сравнении доставок это спасло от «86 190 ₽ экономии»
  как от якобы гарантированной суммы.
- Если источники противоречат друг другу (оферта vs письмо менеджера) — брать консервативную
  цифру, а расхождение выносить ПЕРВЫМ пунктом в список вопросов. Не выбирать молча.
- Считать выводы самому и перепроверять арифметику вручную до показа: 5 сценариев тарифа были
  посчитаны на бумаге и только потом сверены с тем, что вывел Excel.
