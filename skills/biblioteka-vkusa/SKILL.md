# Библиотека вкуса

Каталог: папка `Библиотека-вкуса/` (само приложение в репозиторий не входит, ниже его устройство)
- `screens/` — скриншоты референсов;
- `catalog.json` — разбор (единственное, что правлю при добавлении);
- `index.html` — приложение (фильтр по семьям, карточки, окно с брифом и промптом);
- `server.py` — сервер на http://localhost:8790, `/api/catalog` отдаёт catalog.json + список файлов; новые файлы без записи видны во вкладке «не разобраны»;
- `запустить.bat` — запуск двойным кликом.

Запуск в фоне (Bash, run_in_background): `cd "<папка библиотеки>" && python server.py --no-open`. Если порт занят, сервер уже работает.

## Разбор новых скриншотов

1. `curl -s localhost:8790/api/catalog` → поле `new` = файлы без разбора (или сравнить `ls screens` с `items[].file`).
2. Открыть КАЖДУЮ картинку инструментом Read по очереди. Высокий скриншот смотреть целиком (при необходимости нарезать PIL на куски и смотреть каждый кусок).
3. По каждой вытащить:
   - `site` — название сайта с картинки (логотип, заголовок); `url`, если виден домен;
   - `summary` — одна фраза: на чём держится дизайн (приём, а не пересказ);
   - `tags` — 5–8 коротких тегов по-русски, 1–3 слова: цвет, шрифт, приём, текстура, раскладка («луч прожектора», «сжатый гротеск», «текст сквозь фото»);
   - `fonts` — тип шрифтов (узнать гарнитуру, если уверен; иначе класс: сжатый гротеск, антиква, моно);
   - `colors` — 3–5 цветов `{hex, name}`; hex брать пипеткой из файла (PIL `getpixel` по характерным точкам), не на глаз;
   - `texture` — фото, шум, бумага, стекло, металл, плоско;
   - `grid` — раскладка: колонки, бенто, асимметрия, полноэкранный герой;
   - `note` (необязательно) — пометка «что брать / что не брать»; показывается в карточке и в брифе;
   - `prompt` — промпт картинки на английском под этот стиль с `[ПОДСТАВЬ СВОЙ ОБЪЕКТ]` и `no text, no watermark` в конце.
4. Семьи: сгруппировать ВСЕ скриншоты (старые тоже) по общему стилю. У семьи `id` латиницей, `name` 2–3 слова строчными по-русски («тёмная сцена», «кислотный плакат»), `description` 2 предложения: что общего и на чём держится. Семья из одного скриншота допустима, но сначала попробовать пристроить в существующую. При появлении новых скриншотов можно переразложить старые, если семьи стали точнее, и сказать об этом.
5. Записать catalog.json (UTF-8, валидный JSON; проверить `python -c "import json;json.load(open(...,encoding='utf-8'))"`). Страница подхватит изменения сама за 4 секунды.
6. Отчёт: сколько разобрано, какие семьи получились (название и число).

Тексты описаний без длинных тире в каждом предложении и без нейросетевых оборотов.

## Схема записи

```json
{"file":"lumina.png","site":"Lumina Studio","url":"","family":"temnaya-scena",
 "summary":"Один прожектор сверху делает всю драматургию.",
 "tags":["луч прожектора","чёрная сцена","узкий гротеск","ч/б фото"],
 "fonts":"узкий гротеск","colors":[{"hex":"#0B0B0B","name":"фон"}],
 "texture":"ч/б фото, дым","grid":"полноэкранный герой, веер карточек",
 "prompt":"dark cinematic scene, single dramatic light source, ..., [ПОДСТАВЬ СВОЙ ОБЪЕКТ], no text, no watermark"}
```

## Использование для нового сайта
Просят «возьми стиль X / семью Y»: прочитать запись в catalog.json и посмотреть сам скриншот. Брать приёмы, а не копировать. Чек-лист «Музей AI-слопа» (https://ai-slop.matvei-vibecoder.com) продолжает действовать: если приём референса в нём есть, уточнить у заказчика.
