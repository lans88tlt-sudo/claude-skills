# Скилы для Claude Code и мелкие утилиты

Рабочие наработки: правила и рецепты, проверенные на реальных задачах. Каждая «ловушка» в скилах один раз уже сработала на практике.

## Скилы (`skills/`)

| Скил | Для чего |
|---|---|
| `sajt-ne-bloki` | Лендинг как сценарий прокрутки, а не стопка блоков «герой → преимущества → отзывы → FAQ» |
| `ui-poshagovo` | Пошаговая разработка экрана: бриф → референсы → цвета → шрифт → раскладка → каждый блок отдельно → сборка |
| `biblioteka-vkusa` | Разбор скриншотов сайтов в каталог референсов по семьям стилей |
| `excel-oformlenie` | Оформление .xlsx через openpyxl + Excel COM: автоподбор высоты строк, PDF, ловушки |
| `gsheets-oformlenie` | Оформление Google-таблиц через Sheets API: вставка столбцов, примечания, фильтры |

Установка: скопировать папку скила в `~/.claude/skills/`.

## Расширение для Оперы и Chrome (`opera-unmute-ext/`)

Включает звук на всех вкладках сразу: кнопкой расширения или клавишами **Alt+Shift+M**, а также при каждом запуске браузера.

Установка: `opera://extensions` (или `chrome://extensions`) → «Режим разработчика» → «Загрузить распакованное расширение» → выбрать папку `opera-unmute-ext`.
